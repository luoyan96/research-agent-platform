# 邀请码注册

契约 0.8.0、迁移 010 增加实验室管理员的网页邀请码管理。登录页提供“使用邀请码注册”；成员自己设置账号和密码，注册成功后登录。当前一个账号属于一个实验室，不新增自助创建实验室、多团队切换或手机号验证。普通邀请码只授予该实验室成员身份，任务材料仍按原有权限规则读取。

首次开通由维护者先创建实验室、签发**单次使用**的邀请码，并通过 `designate-manager-invite` 将其指定为管理员开通码。该实验室必须没有成员和管理员，邀请码必须未使用、未撤销、未过期且名额为 1。凭此码注册的账号在同一事务中成为该实验室管理员。管理员登录后从导航栏进入“邀请码管理”，可自行设置 1、7、14 或 29 天有效期、1–50 人名额，查看邀请码状态和撤销。新码只在创建成功的当前页面显示；服务只保存 SHA-256 摘要，列表不返回原码。页面离开、登出或断线后清除显示内容；网络结果不确定时仅重试同一请求。

管理员身份由服务端会话和 `lab_managers` 表核对，普通成员即使直接请求管理 API 也会被拒绝。账号停用后无法使用管理接口；维护者可通过经审计的 `assign-lab-manager` 命令把权限交给同实验室的有效账号。恢复备份仍撤销全部邀请码，需管理员或维护者重新签发。

2026-10-03 已在 ECS 发布提交 `1432c19bf0fdc07ae9919110c24fbcbb057f17ad` 并完成合成 HTTPS 负责人注册、登录、网页签发及撤销验收。测试邀请码已撤销，测试账号已停用；真实实验室的单次负责人开通码已准备好，负责人本人尚未注册。部署与备份证据见 [ECS 记录](ecs.md)。

## 维护者签发与撤销

复用生产 `operate.js` 的 stdin JSON 入口及 OPERATOR_ID 审计身份；不能通过网页匿名接口签发邀请码。先用既有 create-lab 创建实验室。每个邀请码使用至少 24 个密码学随机字节生成，例如 `RAP-` 加随机字节的 base64url；仅将 SHA-256 摘要作为 codeHash 写入维护命令，不使用姓名、日期或短口令。原码通过获准的受控文件交实验室负责人，不写入 Git、网页默认值、命令历史、日志或公开文档。

新增三个命令，均包含 action、requestId、labId，重复写命令沿用原 requestId 和内容：

| action | 附加字段 | 行为 |
| --- | --- | --- |
| create-registration-invite | inviteId、codeHash、expiresAt、maxUses | 摘要须 64 位小写十六进制；有效期从签发起不超过 30 天；名额 1–50 人 |
| inspect-registration-invite | inviteId | 返回所属实验室、有效期、已用/总名额和撤销时间；不返回原码或摘要 |
| revoke-registration-invite | inviteId | 立即停止后续注册；不影响已经注册的成员，成员停用仍走既有命令 |
| designate-manager-invite | inviteId | 仅在空实验室中标记未使用的单次邀请码为管理员开通码 |
| assign-lab-manager | memberId | 维护者将管理员身份交给同实验室的有效账号，用于恢复或交接 |

首次管理员邀请码只供负责人本人使用，名额 1。之后管理员可在网页签发七天、十个名额的成员邀请码，把网址和邀请码交给受邀同事即可，无需替同事设置密码。到期、用完或撤销后签发新码；不修改原码计数。CLI 仍是受限的维护通道，普通成员不能签发或扩大邀请。

当前不信任任意转发 IP，Nginx 后的注册限流按同一个代理地址合并计算：每 15 分钟最多 20 次合法格式的注册请求，包括重试；跨进程同时最多两个密码计算。遇到限流等窗口恢复，不连续点击。该配置适合当前十人试点，扩大规模前须单独设计可信代理和容量策略。

## 升级与恢复

部署前停止本平台写入并使用旧发布版本备份数据库和附件，保留旧代码与备份。新版本应用 010 两次检查幂等，再同时切换前后端契约 0.8.0。旧账号、任务、密码和会话保留；没有默认生产邀请码，也不会让最先注册者自动成为管理员。必须由维护者明确指定开通码。

新版本恢复工具撤销恢复库中的全部邀请码，保留历史名额和账号；恢复后由维护者重新签发。旧版本备份应先用对应旧发布恢复到新目录，之后再执行新版本迁移，不能把 008 代码直接指向已升级 009 的数据库。

浏览器只在当前注册页内存中保留未确定请求及密码，不写 localStorage、sessionStorage 或 URL。离开页面清空；注册成功清空并给出登录入口。网络错误重试同一个请求，后端成功回执不会重复消耗名额。注册不代表真实成员试用验收完成。
