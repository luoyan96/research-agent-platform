# 当前代码与目标平台

当前两个基础包能够独立构建，尚无平台 Web 服务。

```text
agents/skills（唯一方法来源）
        ↓ 构建时复制
packages/research-skills（正文与参考目录）

packages/research-core（Project / Artifact 与本地存储）
        ↓ 计划通过适配调用
integrations/deepseek-harness（源码已迁入，SDK 与运行待验证）
```

目标平台的统一网页负责项目、任务和能力发现，服务端负责成员授权、知识与记忆、任务持久化和调度。隔离的执行环境运行 Harness，通过按任务授权的数据接口读取资料与提交成果。

当前本地 ArtifactStore 适合基础验证，不是多人平台的权威数据服务。未来应通过清晰的存储接口迁移到事务数据库和文件存储，避免多个执行进程直接改同一个本地索引。

任务与 Harness 会话需要明确关联，状态持久化由平台掌握。浏览器关闭不等同于服务器终止；会话记录可以恢复也不代表任意外部脚本都能无损续跑。详见[产品规划](product-plan.md)。

Git 维护代码、方法、评测案例和组织共识；运行数据、私人资料和成员记忆由平台管理。模型调用和知识检索是执行时的活动，构建与单元测试不依赖模型 API。
