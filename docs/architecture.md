# 当前代码与目标平台

截至 2026-09-30，集成分支已有两个基础包、契约 0.6.2、B5a API/运维工具、F5a 网页及固定 Harness runtime。多人任务权威状态在 SQLite 事务数据库中；G1—G3 及 G4a 的人类协作、变化协调、真实规划/执行、授权复用与公共方法维护已复核。G5a 已补账号维护、生产参考路径、数据库与附件恢复并共同通过；实际部署与试用见[启动说明](pilot-launch.md)。当前状态见[第一阶段范围](phase-one.md)，启动见[B5a 联调包](development/b5a-handoff.md)。

```text
apps/web（F5a 任务协作、授权复用与首次使用指引） → apps/api（会话、鉴权、事务、快照） → SQLite
        ↕ packages/contracts 0.6.2 / AdaptiveReply 1.0.0             ↕ 执行队列/租约
                              ↓ 每次访问重新鉴权
                         私有附件目录（版本引用、哈希校验）

apps/api worker（可信协调器：版本、授权、预算、派发与写回）
        ↓ 限定文本输入；不传数据库、cookie 或工具
integrations/deepseek-harness/runtime（官方 0.2.0-rc.1 LlmRuntime 子进程）
        ↓ 一次受限调用
DeepSeek provider → 校验结构与引文 → 保存候选 → 人确认提交 → 指定版本验收

agents/skills（唯一方法来源）
        ↓ 构建时复制
packages/research-skills（正文与参考目录；未自动接入团队运行）

packages/research-core（本地 Project / Artifact）→ 历史六工具适配（不挂载到团队 worker）
```

当前读取使用绑定身份、实验室与数据版本的短期快照。业务或权限变化会使旧快照失效；页面清理旧组合并要求重新读取。它不是历史数据快照，也不是实时推送；成员承诺按权限过滤，自报时间不等于实际负荷。

前台围绕一个需求入口、一份协作方案和持续进展展开；任务分配、状态和权限由后台维护。服务端保存方案版本、确认去重、邀请与认领、成员承诺、已开放的任务依赖、变更、交付和验收。worker 经服务权限检查读取限定文本；模型只产生待校验建议或候选，不能授权或改变任务完成状态。规则见[任务分配与能力边界](task-allocation.md)，实际证据见 [G4a 报告](development/reports/G4a-overall-2026-09-30.md)。附件元数据在数据库、内容在私有目录；停写备份与新路径恢复已验收；恢复撤销旧会话、标记未结束运行待检查，崩溃遗留文件的自动治理仍未开放。

结论保存不可变版本、来源和范围；复用记录来源依赖，撤权限制派生任务/运行/缓存。公共方法版本与启用配置代次分离，只用主动获准的样例；本人授权历史可在原任务找回与撤回，维护者权限不扩大为来源任务访问权。

执行队列独立于通知 outbox，派发及写回都校验任务、能力配置、输入与权限版本。排队任务可重新领取；运行租约过期标为中断，未知用量不自动重放。该受限 LlmRuntime 组合不是完整编程代理循环；子进程虽不接收工具或平台数据库路径，仍使用同一 OS 用户，不能据此宣称系统级沙箱隔离。

当前共同规划仅使用授权任务上下文、公共能力和成员愿意公开的信息；可承接列表尚无专长/负荷排序。长期权限设计允许个人执行调用本人私有能力，现阶段私人方法仍留在平台外；私有配置、记录与反馈不进入公共匹配、共同日志或导出。任务发起人的业务权限不扩展到他人的私有能力；应用权限与服务器运维可读性需要分别评估，不能把界面隐藏当成保密隔离。

当前本地 ArtifactStore 适合基础验证，不是多人平台的权威数据服务。B1 已另建事务数据库；后续成果存储与执行适配也应通过授权服务调用，避免多个执行进程直接改同一个本地索引。

任务与 Harness 会话需要明确关联，状态持久化由平台掌握。浏览器关闭不等同于服务器终止；会话记录可以恢复也不代表任意外部脚本都能无损续跑。技术执行结束与成果被用户采用分别记录。当前产品优先级与验收见[产品规划](product-plan.md)，原有运行结构建议、上游核查和迁移前资产盘点保留在[工程依据](engineering-baseline.md)，其中历史状态不代表本仓库当前实现。

Git 维护代码、方法、评测案例和组织共识；运行数据、私人资料和成员记忆由平台管理。模型调用和知识检索是执行时的活动，构建与单元测试不依赖模型 API。
