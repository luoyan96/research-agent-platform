## 实现与持久化

真实 Fastify HTTP、Cookie 会话、CSRF 与服务端成员身份继续沿用 G1；SQLite 磁盘事务同时保存任务/承诺版本、提议决策、事件、幂等结果和 outbox 意图。依赖检查拒绝自环、间接环，指定交付只有验收后才满足开始条件；未指定版本在开始时绑定已验收版本，不自动漂移。关键变化写入下游影响，已有交付和验收保留，恢复要求依赖有效、显式影响复核及恢复动作。

范围、日期和依赖变更须提议，未获所有必要成员接受前保留原承诺；拒绝、过期和历史决策可查。建议时间、硬截止、成员承诺保留独立值、来源、时区，未知仍为 null。退出后候选人只获摘要邀请，另行接受才形成承诺；撤销最后一个待接受邀请回到未分配。取消保留队列证据，将 pending/leased 意图取消，不伪称撤销已经发生的外部效果。

附件采用私有文件目录与事务元数据，内容不可原地覆盖；交付保存附件 ID/版本引用。上传、下载、提交/验收与缓存重放重新检查当前权限。退出、撤权和附件撤回后，旧链接、快照、上传/交付/验收成功缓存不能恢复读取。取消后发起人可审计任务历史，但不能继续下载附件。

详情、人员承诺、授权四列计数、待回应变更、分页历史继续共享 B2a 的事务快照与 ACL。聚合计算完整授权集合，不将当前页当总量；不读取成员私人方法。不可见上游的影响来源 ID/版本脱敏，不能据影响接口枚举受限任务。

新增 [005-coordination.sql](../../../apps/api/migrations/005-coordination.sql)，不改 001—004。升级保留既有方案、会话、承诺、可用时间、交付、验收和幂等结果，回填当前任务/承诺版本与依赖边。不能恢复 B2a 当时没有保存的早期任务版本。实际有数据的 001—004 数据库执行迁移两次并比较旧表记录，之后真实服务通过原会话读取旧成果。

## 环境、启动与合成资料

Windows PowerShell；Node.js 24.19.0、pnpm 11.21.0、TypeScript 6.0.3、Vitest 4.1.8、Fastify 5.12.5；事务数据库为 Node 内置 SQLite。未新增 npm 依赖，pnpm-lock.yaml 和 vitest.config.ts 保持共同基线内容。

启动顺序：`pnpm install --frozen-lockfile` → `pnpm build` → `pnpm db:migrate` → `pnpm db:seed` → `pnpm db:credentials` → `pnpm api:start`，另终端执行 `pnpm seed:coordination`。配置名：NODE_ENV、DATABASE_PATH、BLOB_ROOT、HOST、PORT、APP_ORIGIN、TEST_CREDENTIALS_FILE、API_URL。完整可复制 PowerShell 命令、认证头、请求和错误例子见 [前端联调包](../b2b-handoff.md)。

随机测试密码只存 Git 忽略的本地文件，不写报告、日志或仓库。合成 A/B/C seed 通过真实 HTTP 形成上游阻塞、下游暂停、待回应变更、带附件旧交付和待 C 接受的转交；重复执行不重建或重置进展。旧业务数据库只备份并迁移，不运行演示 seed。文件和数据库需一起备份。

## 未完成、限制与集成交接

- `confirmed_decision` 依赖、草案跨任务附件复用、在变更提议中直接替换牵头者返回 501；转交使用退出加候选人独立接受的已实现流程。
- 每任务提议/附件上限 100；详情影响最多 100 并标记截断、未复核优先；历史事件授权分页。附件 1 byte—10 MiB，仅 text/plain、PDF、PNG；签名/UTF-8 检查不是病毒扫描。
- 文件系统和 SQLite 不具备跨资源原子提交；普通失败清理本次文件，崩溃可能留下不可经 API 读取的孤儿。正式备份恢复、孤儿清理命令、配额与病毒扫描尚未运维验收。
- 不开放真实 AI worker、外部通知或新增渠道；outbox 只表示持久派发意图。Harness 最近已知状态仍是“固定依赖安装阻塞、真实调用未验证”，本批未处理 B3，不宣称 AI 已接通。
- 不实现搜索引擎、导出平台或学校管理模块。F2a 界面未改变；仅既有前端契约版本测试随 0.4.0 同步。F2b 须消费新增变更待办、影响、附件与动作状态后另行浏览器验收。
- 共同根 CI 保留后端真实进程与前端生产隔离，不选择任意一侧覆盖。package.json 只增专项检查和合成 seed；锁文件/测试根配置未改。最终发布和 PR 集成仍由总体验收任务处理；本分支没有推送、部署或合并 main。
