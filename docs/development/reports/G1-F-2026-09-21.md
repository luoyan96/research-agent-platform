## 已完成与操作路径

入口 `#/` → 手工方案 `#/plans/new` → 保存至 `#/plans/{id}` → 修改/保存版本 → 确认已保存版本 → `#/tasks/{id}`。任务列表 `#/lab` 提供服务端授权的基本 lab/mine 分页，不冒充完整实验室聚合。

邀请 B 后，B 从“我参与的”读取安全摘要并接受/拒绝；开放认领从“实验室”找到。接受后才显示真实承诺和完整任务。承接者开始 → 提交文本成果 → A 退回 → B 重新提交 → A 验收具体交付版本。详情呈现任务/方案/邀请记录/交付/验收版本及结果，不要求个人工具、私有能力或过程日志。

开放认领摘要由用户单独填写，不自动复用完整目标；页面明确摘要/交付/验收要求会公开。浏览器回归断言承接前页面不含完整目标。已存在的公共 AI 分配显示尚未接通并保留原值，不在编辑时静默改为本人承担。

请求按共享 Schema 校验；服务器数据是权威来源。双击在途去重，同一失败请求保存不可变正文和原幂等键，重试不换键；新意图必须先明确放弃未决请求，再创建新键。409 提示读取、比较并重新确认；方案编辑刷新保留原编辑基准版本，不能偷偷换 expectedVersion。读取失败没有成功示例，403/404 清除旧受限内容。

AI 明确不可用；手工表单不会伪造建议。保存后草案 URL 可收藏恢复，草案历史列表未接通。未保存输入只在当前页面内存保存；不把本地状态视作持久化服务。
