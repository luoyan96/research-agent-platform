## 从现有界面到最小修改

先用原页面走完 11 组 G1 浏览器流程，确认手工主线可用，再补帮助。没有改样式、固定导航布局或业务流程，也没有增加问卷、常驻侧栏或流程中心。

- [成员短指引](../../first-use.md)及页面 `#/help`：提出需求、核对日期、保存/确认、回应、执行交付、人工验收；请求/草案找回、结论选择、本人样例撤回和故障处理。入口帮助默认折叠，登录页也可查看；帮助不依赖 API 或登录。
- 错误后给出下一步：模型/能力不可用可手工协作，未决原请求需重试或明确放弃；断线先恢复服务；同账号失效可重登恢复，重置用新密码，停用联系管理员。请求编号折叠核对，保留已有错误码和冲突比较。
- 当前公共文本能力只支持获准 UTF-8 纯文本，空材料提示说明 PDF/图片不能自动识别，仍可人工交付。运行中断提示读取、核对及联系维护者，不伪造成功或确定费用。
- 非 JSON 失败响应（如代理 HTML 502）现在归为 `SERVICE_UNAVAILABLE`；成功但不可解析仍拒绝，取消读取后的晚到响应仍丢弃。新增两条行为单测覆盖原 key/body 保留、响应失效及取消；没有吞异常或演示回退。
- 修正文档中“失败请求只能收藏链接”的过时说法；本人生成请求列表已经由 G4a 交付。

没有改变模型提示、能力、工具、运行底座或外部调用路径。没有付费调用仅为证明文案修改。

本地短期自签证书仅用于 loopback 合成环境，未安装系统信任；测试 context 显式容许该环境证书，不是可直接部署的证书配置。模型密钥从子进程环境移除；为验证真实失败请求找回，API/worker 开启生成入口但缺少 provider 凭据，真实服务把请求记录为 failed。没有生成成功或模型效果证据；正常未配置环境应按 B5a 文档保持 AI 关闭。

## 启动与重跑

使用 [B5a 完整联调包](../b5a-handoff.md)完成构建、绝对路径配置、正式维护账号、API/worker和生产静态HTTPS入口。用户入口为该配置的 `APP_ORIGIN/`；短指引为 `APP_ORIGIN/#/help`。正式使用需要获准证书、实际主机和账号分发安排，本批没有进行上线。

浏览器脚本需独立且可重置/停用的合成成员，labId前缀必须 `f5a_synthetic_`。私有JSON数组包含 `labId/memberId/username/password`，由正式维护流程产生；不放密码在argv、终端日志、报告或Git。环境中的 DATABASE_PATH/BLOB_ROOT/OPERATOR_ID必须指向这次自己的隔离环境，因为脚本会通过官方工具重置和停用合成账号。

```powershell
# 先在独立终端按 B5a 文档启动生产 API、worker、HTTPS 静态代理。
$env:NODE_ENV='production'
$env:F5A_BASE_URL='https://127.0.0.1:4491'
$env:F5A_SERVICE_SHA='8f609153b4e74d49816af18819dcc07b8a895316'
$env:F5A_CREDENTIALS_FILE='<私有合成账号文件的绝对路径>'
$env:F5A_EVIDENCE_DIR='<自己的证据目录>'
$env:PLAYWRIGHT_MODULE='<已安装 Playwright 的 index.mjs>'
node apps/web/scripts/check-f5a-browser.mjs
pnpm run ci
```

脚本的找回分支需要可产生真实排队/失败请求的环境；本次没有模型凭据，worker留下失败记录。若只配置AI关闭，先做手工协作，不能把请求列表检查计通过。断API检查在总控停止自己持有的API进程后执行；仅停止本任务进程，不能按名称结束全部node。最终API/worker/代理与浏览器均已停止；私有环境保留，不作为运行中的部署。
