# 科研能力与 Skills

这里保存十项科研方法的唯一源文件。它们包含输入要求、方法、产物、证据边界和失败处理；执行时仍需实际工具和资料。按任务评测后，才能作为平台能力发布。

| Skill | 用途 |
|---|---|
| [paper-search-pro](skills/paper-search-pro/SKILL.md) | 文献发现、去重与排序简报 |
| [systematic-literature-review](skills/systematic-literature-review/SKILL.md) | 系统/范围综述 |
| [academic-paper-review](skills/academic-paper-review/SKILL.md) | 论文精读与审稿 |
| [hypothesis-research-loop](skills/hypothesis-research-loop/SKILL.md) | 假设与最小实验规划 |
| [statistical-result-analysis](skills/statistical-result-analysis/SKILL.md) | 数据审计与统计报告 |
| [research-writing-and-rebuttal](skills/research-writing-and-rebuttal/SKILL.md) | 学术写作、修稿与回复 |
| [research-thesis](skills/research-thesis/SKILL.md) | 可证伪研究主张 |
| [novelty-red-team](skills/novelty-red-team/SKILL.md) | 创新性与近邻工作核对 |
| [experiment-matrix](skills/experiment-matrix/SKILL.md) | 主张与实验对应 |
| [iclr-red-team](skills/iclr-red-team/SKILL.md) | 投稿前审查方法 |

创建方法使用 [Skill 模板](templates/SKILL.md)，成果格式参考 [Artifact 模板](templates/artifact.md)，验证情境登记到[评测矩阵](../evaluations/matrix.md)。源仓库的评测情境已迁入，但效果评测尚未运行。

Skill 不能为不存在的工具编造参数或结果。具体执行以当前工具 schema 与用户授权为准；本仓库默认检查不会自动执行这些方法。
