# Red-team gate

Use severity `blocker`, `major`, `minor`, `question`. A blocker is a defect that makes the central contribution unsupported, noncompliant, or impossible to assess; a major issue plausibly changes the decision; minor issues improve clarity only.

For every issue record a specific evidence locator and a verifiable repair. Treat the target-year official author guide as authoritative for page limits, formatting, double blind, declarations, and dates.
