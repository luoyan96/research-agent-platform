# Search report contract

`library.json` records: stable ID, title, authors, year, DOI, source IDs/URLs, query IDs, retrieval time, abstract availability, verification status, relevance tier, and deduplication lineage. `search-log.json` records every attempted source, query, filters, count, and failure.

The briefing begins with question, tier, scope, source coverage, deduplication funnel, and limitations; then gives ranked papers, thematic clusters, and next queries. HTML output mirrors the data, not additional claims.
