# SLR reporting checklist

Record question/framework, protocol date, all information sources, exact strategies, eligibility criteria, screening process, exclusion reasons, data items, extraction method, quality appraisal, synthesis method, study flow, included-study table, certainty/limitations, and funding/conflict disclosures when known.

Use only items supported by the review workflow. A partial checklist means the report is a scoped review, not a PRISMA-complete review.
